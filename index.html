雙輪盤Ruleta doble

兩個輪盤分別抽出姓名與任務，為課堂增添驚喜。支援自訂項目、設定備份與投影。Sortea nombres y retos con dos ruletas. Personaliza las opciones, guarda la configuración y usa la pantalla completa.

使用方式Cómo usarla

先編輯兩個輪盤的項目，再按「開始雙輪盤」。可分別抽選或同時轉動。請使用 JSON 匯出／匯入保存不同班級的設定。Edita las opciones de ambas ruletas y pulsa «Ir a las ruletas». Gíralas por separado o juntas. Exporta e importa archivos JSON para guardar la configuración de cada grupo.
